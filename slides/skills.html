A skill is a folder with a SKILL.md: a name, a description, and instructions. At the start of a session the harness lists only the names and descriptions, so skills cost almost nothing until used. When the model decides one matches the task, it calls the Skill tool, and the full instructions are added to the conversation. Extra files in the skill folder are read only if the task needs them. The harness does not load a skill on its own; the model picks it from the description, or you force it with slash skill-name. So the description is everything: say when to use it, not just what it is. Examples: humanizer and stop-slop are public skills that strip AI tells from writing; ffmpeg and face-recognition are the skills from our face workshop.

The full exercise
All morning you corrected the same things: who you write for, how to open, no hashtags, don't add what isn't in the brief. Memory is where those go so you never type them again. The agent reads your brief and the gap between its draft and your own edit, and proposes up to five lines. You delete anything that isn't true of everything you write, then save. Claude Code reads CLAUDE.md, Codex reads AGENTS.md, and mo reads either. Then start a fresh session and give it the bare ask, the kind of prompt from step one. In our tests, both tools opened with the takeaway and left out the hashtags without being told. Memory is loaded every session, so keep it short: who you are and your rules. How you phrase things stays in the voice skill. To use it in every project, move the lines to the file in your home folder.

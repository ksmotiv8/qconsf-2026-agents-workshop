The workshop repo
Time to turn yours on. Install Claude Code, Codex, or both. Make an empty folder and start the agent there. The first time, it opens a browser so you can log in. Now, instead of typing git clone, ask for what you want: clone the workshop repo into this folder and tell me what is in it. Into this folder matters: the rest of the day runs from here. That is the whole idea of today in one prompt. You state the outcome, the agent picks the commands, and it asks before it runs them. Keep going while I talk. If you get stuck, raise your hand or ask the agent what went wrong. Everything we do later starts from this folder.

Before your prompt ever reaches the model, the harness puts a lot in front of it. A system prompt with identity, rules, and environment details. Tool definitions. Your memory files. The skills list. The conversation so far. Your prompt is the thin slice at the bottom. And it is not sent once. Every turn, every tool call, the harness sends the whole stack again, with the conversation a little longer each time. When it gets too long, the harness compacts the older turns into a summary and keeps going, so what goes over is the current context, not every word ever said. The Codex instructions for GPT-6.2 are about 4,000 words; the latest published claude.ai prompt for Opus 5.5 is about 5,200. They are full of patches for real behavior. GPT-6.2 is told not to invent labels like exact-head checks, which tells you it did. It is told never to repurpose the HOME variable, which tells you it did that too. Claude is told not to curse unless you do, and never to use bullet points when declining, to soften the blow. These patches come and go with each model: GPT-5.5's instructions told it, twice, never to talk about goblins, gremlins, raccoons, or pigeons, and that it is clumsy in the interactive git console. Neither line made it into GPT-6.2. The lesson: every one of these lines is someone correcting the model through context. You can do the same thing with your own memory files.

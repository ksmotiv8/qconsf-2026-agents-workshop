Read the whole file
Here is the whole skill file, drawn to scale. The front matter is four lines, and it is the only part the agent sees until the skill applies. Its job is to say when to use it: server modules, not ordinary Rust programs that talk to Valkey. Then the goal: a module that builds, loads, and passes command-level checks. Establish the target says check versions, platform, and what you are allowed to touch, and infer them from the project before asking. Route the work points to four references that load only when needed. The workflow says load the smallest thing first. The non-negotiables are the lessons learned the hard way: the module runs inside the server, so a panic takes it down. And the handoff says never claim success from a compile or a PING.

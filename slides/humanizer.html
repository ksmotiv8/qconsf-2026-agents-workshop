This is one of the most popular skills on GitHub, over 70,000 stars. It is a single markdown file. The top block in green is all the model sees at the start: a name and a description that says when to use it, with a list of the tells it catches. That is the trigger. When you ask it to edit prose, the model loads the whole file: about 500 lines that walk through 26 AI writing patterns in six groups, from "not X but Y" contrasts and one-line closers to forced triads, dashes, inflated claims, and chatbot leftovers. Notice there is no code. A skill is instructions in plain English, the same as a system prompt. We will use this one in the writing exercise.

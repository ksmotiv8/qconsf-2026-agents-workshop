People mix these up, so here is the difference. A skill is the instructions: a folder with a SKILL.md, the name and description the agent sees up front, and the steps it reads when the task matches. It is an open format, so the same folder works in Claude Code, Codex, and mo. A skill doesn't need a plugin: my-voice and humanizer are just folders. A plugin is a package for sharing extensions, skills among them. Claude Code and Codex both have plugins and marketplaces. One plugin can bundle skills, slash commands, subagents, hooks, and MCP servers. In Claude Code you install one with slash plugin install. In Codex it is codex plugin add, or slash plugins in a session. Codex even reads Claude Code marketplaces, so the same plugin can install in both. mo has no plugins yet; it just reads skill folders. In step 7 we use frontend-design, which ships as a plugin but is really one skill. Claude Code and Codex install the plugin. In mo you ask the agent to copy the skill out of the repo, and you get the same instructions.

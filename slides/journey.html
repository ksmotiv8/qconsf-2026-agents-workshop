The journey of a prompt

You type an ask. The harness does not rewrite it. It wraps it in context: system instructions, your memory files, the tool definitions, the list of skills, and the conversation so far. The whole thing goes to the model. The model does not touch your machine. It answers with a tool call: read this file, run this command, load this skill. The harness runs it, sometimes after asking you, appends the result to the conversation, and sends the whole conversation back. That is one trip. A single ask is usually many trips: our coding runs averaged over 30 model requests per task. When the model stops asking for tools, its answer comes back to you through the harness.

Claude Code memory docs
Both tools have two kinds of memory. The first is the file you just wrote: CLAUDE.md for Claude Code, AGENTS.md for Codex. You write it, you can read it, and it loads every session. The one in this folder applies here; the one in your home folder applies everywhere. Claude Code also reads AGENTS.md when there's no CLAUDE.md. The second kind the agent writes for itself. Claude Code's auto memory is on by default: as you correct it, it saves notes in a memory folder per project, and you can see or turn it off with slash memory. So it may already have saved something from this morning. Go look. Codex has memories too, but they're off by default; turn them on with slash memories, and it summarizes past sessions in the background. And what ChatGPT remembers about you in the chat app doesn't carry over into Codex. Both vendors say the same thing: rules that must always apply go in the file. Automatic memory is a recall layer.

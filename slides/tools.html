The model can't do anything on its own. It can only ask. The harness tells it which tools exist: a name, a description, and the inputs each one takes. The model answers with a structured call, like run cargo test. The harness runs it, sometimes after asking your permission, and the output goes back into the conversation. Built-in tools read, edit, and write files, run shell commands, search code and the web. MCP servers add more: GitHub, Slack, your database. Every action you see an agent take is one of these calls.

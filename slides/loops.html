More examples
Everything today was one prompt and one answer. Three tools take you past that. A goal keeps the agent going until a condition is true. In Claude Code, after every turn a separate, fresh model checks whether the condition holds, and if not, the agent takes another turn. Codex has the same idea, also called slash goal, with pause and resume. Here is one for the Valkey exercise: every case in the review table passes against the release module, or stop after twenty turns. Write it as something the agent can prove by running a command. Loop is different: it reruns a prompt on a schedule, like checking a deploy every five minutes. And workflows, in Claude Code, are a script that fans work out to many agents in a fixed order, like five parallel reviewers and then a verifier for every finding.

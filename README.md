# Supercharge Your Work With Claude Code and Codex

QConSF 2026 training workshop (Khawaja Shams, Ruth Linehan).

## Start here

1. Install Claude Code, Codex, or both. No plan? Use
   [mo on open models](exercises/MOMENTO.md).

   ```
   curl -fsSL https://claude.ai/install.sh | bash   # Claude Code
   npm i -g @openai/codex                           # Codex
   ```

2. Make an empty folder and start the agent in it:

   ```
   mkdir qcon && cd qcon
   claude    # or: codex, or: mo
   ```

3. Ask for the repo:

   > Clone ksmotiv8/qconsf-2026-agents-workshop from GitHub into this
   > folder and tell me what's in it.

   Check: the agent's folder now has `exercises/` in it. If it cloned into
   a subfolder instead, quit, `cd qconsf-2026-agents-workshop`, and start
   the agent again there. Or skip the agent and run
   `git clone https://github.com/ksmotiv8/qconsf-2026-agents-workshop.git`
   yourself.

## Exercises

- [Build a Valkey module with a skill](exercises/VALKEY-MODULE.md): implement
  Two Sum in Rust, benchmark it, and carry a reviewed lesson into a fresh session.
- [Slop to signal](exercises/SLOP-TO-SIGNAL.md): research the talks, get interviewed, write
  from a brief, add your voice, edit a LinkedIn post you would send, and
  save what you learned to memory. Or take the
  [Slack track](exercises/SLACK.md).
- [Compare and design](exercises/DESIGN.md): step 9, a page with
  every version side by side, redesigned with frontend-design.
- [Devil's advocate](exercises/DEVILS-ADVOCATE.md): turn the agent into
  the skeptical reader before your real audience sees the draft.
- [Dual review](exercises/DUAL-REVIEW.md): Claude Code runs Codex as a
  second reviewer on the same diff.
- [Loops, workflows, and goals](exercises/LOOPS-WORKFLOWS-GOALS.md): when
  one prompt, one answer is the wrong shape for the work.

## The deck

- `slides/<id>.html`: one file per slide; `order.txt` sets the order
- `deck.md`: text version, generated by the build
- `index.html`: the built deck (arrows to move, P for notes, A for appendix)
- `outline.md`: the working outline

Build: `python3 deck.py build .`
